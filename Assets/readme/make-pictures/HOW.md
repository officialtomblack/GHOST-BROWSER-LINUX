# How the README pictures were made

- The three `.svg` graphics are hand-written (the 20-steps one is generated by a short script from the step list).
- Terminal pictures: the `.txt` files here hold real output, trimmed, with real IP addresses replaced by example
  ones (203.0.113.x, 198.51.100.x) and `#` notes added. `python3 term.py FILE.txt "TITLE" out.html`, then
  `bash shot.sh out.html out.png` (headless Chrome, 2x, cropped).
  - `tests.txt`: lines from `bash tests.sh` and the last line of `bash install-tests.sh`.
  - `killswitch.txt`: `sudo bash killswitch-test.sh` with Ghost Browser open on a real VPN (2026-11-15).
  - `check.txt`: `ghost-browser.sh --check` on a real VPN (2026-11-15).
- `social-preview.png` (1280x640) is `social.html` screenshotted.
